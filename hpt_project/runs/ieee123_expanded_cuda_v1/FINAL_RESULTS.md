# IEEE123 六台 HPT 扩容重训结果

在相同执行规则下，联合 DFL 相对继续 MSE 在两个测试分组的平均损耗和电压风险均较低。冻结预测器在两组中损耗最低。九月联合 DFL 的调压改善跨三个种子，而节能幅度依赖初始化。

## 试验与核验

三个训练方案均训练动作网络。冻结组固定预测器，MSE 组继续用光伏标签更新预测器，联合组额外向预测器传递调度反馈。每轮遍历 78,694 个训练周期，同一种子的三组共享训练轮数。种子 11、23 各跑三轮，37 跑两轮。按验证评分最低值锁定检查点。种子 11 三组都选第二轮，种子 23 冻结和联合选第二轮、MSE 选第一轮，种子 37 三组都选第一轮。

五月有 4 个新日期、11 个窗口。九月有 30 个历史日期上的 75 个新窗口，与原窗口和初始化历史隔离。各方案和种子均回放相同的 86 条轨迹，共核对 774 条窗口结果。每个窗口 90 分钟，各日期内先平均窗口，再等权汇总日期和种子。峰值是各窗口最严重的一次。耗时是闭环测试中 CPU 决策和审核的窗口 P50 或 P95 的平均值。

## 配对差异

相对继续 MSE，九月联合 DFL 每 90 分钟平均少损耗 0.313 kWh（0.42%），少越限 100.3 秒（18.6%）。先在同一日期平均三个种子，再按日期做三天循环区块自助抽样，10,000 次抽样所得 95% 区间分别为少损耗 0.245–0.386 kWh 和少越限 43.6–157.1 秒。过载少 18.9 秒，其差值区间为 −47.8 至 +2.6 秒。这些区间只反映给定三个种子下的日期波动。九月三个种子越限均改善，种子 11、23、37 的损耗差分别为 +0.127、−0.437、−0.628 kWh。五月仅四天，使用描述性配对结果。

相对冻结预测器，联合 DFL 的五月和九月损耗分别增加 0.305 和 0.103 kWh，越限分别减少 127.4 和 37.7 秒。九月损耗增加的日期区块区间为 0.062–0.147 kWh，越限时长差的区间跨零，越限峰值差的区间为 −0.000369 至 −0.000071 p.u.。本试验比较三种学习方案在各自选中工作点的运行表现；要回答同等风险下的经济性，仍需预先指定同一风险标准。

原始输出保存在各方案与种子目录，选模见 selection.json，完整均值与日期配对区间见 test_summary.csv 和 paired_differences.csv。可通过 hpt_project/tools/ieee123_expanded_results.py 重算。
